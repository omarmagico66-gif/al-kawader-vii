# AL Kawader VII V2.2 — تجهيز النشر على Cloudflare Workers

هذه نسخة تجهيز للنشر وليست منشورة بعد. تم الحفاظ على ملفات التطبيق وقاعدة Supabase كما هي، وإضافة إعداد OpenNext/Wrangler وفق دليل Cloudflare الرسمي لتشغيل Next.js على Workers.

## النشر من جهاز كمبيوتر
1. فك ضغط الملف.
2. افتح Terminal داخل مجلد `AL-Kawader-VII-V2`.
3. نفّذ: `npm install`
4. نفّذ: `npx wrangler login` ثم أكمل تسجيل الدخول إلى حساب Cloudflare في المتصفح.
5. نفّذ: `npm run preview` لاختبار التطبيق محليًا في بيئة Workers.
6. بعد نجاح الاختبار فقط نفّذ: `npm run deploy`.
7. سيعرض Wrangler رابط `workers.dev` الخاص بالتطبيق.

## ملاحظات مهمة قبل الاستخدام
- هذه الحزمة لا تعني أن النشر تم. يلزم تسجيل الدخول إلى حساب Cloudflare من جهازك وتشغيل أوامر النشر.
- لا يوجد نشر تلقائي أو وصول إلى حساب Cloudflare من داخل هذه الحزمة.
- مصادقة المدير متصلة بـ Supabase. مفتاح Supabase الموجود في الواجهة هو publishable key وليس service-role secret.
- هذه النسخة ما زالت Admin Auth فقط؛ QR للفنيين، الحفظ الفعلي للزيارات، إدارة العقود والمواعيد والتنبيهات غير مكتملة.
- لا تستخدمها لإدارة بيانات تشغيلية حقيقية قبل استكمال الوظائف واختبار الصلاحيات والنسخ الاحتياطي.
- لا تشارك أي مفاتيح سرية أو كلمات مرور في المحادثة.
