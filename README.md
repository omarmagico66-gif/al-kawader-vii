# AL Kawader VII — V2
تاريخ الإنشاء: 2026-11-26

## محتويات النسخة
- واجهة عربية RTL.
- نموذج تسجيل زيارة دورية.
- 12 نظام سلامة مع حالات: سليم / في عطل / غير موجود.
- وصف إلزامي عند وجود عطل، ومرفقات صورة/فيديو اختيارية في النموذج.
- حقول الشركة والموقع وبيانات مسؤول الموقع الاختيارية.
- طلب إذن GPS والتحقق من وجود الإحداثيات قبل إنهاء النموذج.
- تفاصيل طفايات الحريق واحتياج التعبئة.
- سجل أكواد تجريبي داخل جلسة المتصفح.

## حدود مهمة
هذه نسخة واجهة تجريبية فقط. لا توجد قاعدة بيانات أو مصادقة حقيقية أو إرسال بريد أو مشاركة واتساب أو تخزين آمن للملفات. سجل الزيارات مؤقت في حالة الصفحة ولا يعد حفظاً دائماً. لا تستخدم بيانات حقيقية حساسة في الاختبار.

## تحديث المصادقة
- مصادقة حقيقية عبر Supabase Auth لحساب المدير.
- الواجهة تعرض كلمة مرور فقط وتستخدم البريد الإداري داخلياً.
- التحقق من الدور admin والحالة active قبل الدخول.
- مفتاح publishable عام فقط؛ لا توجد مفاتيح سرية في الواجهة.
- تفعيل الفنيين عبر QR لم يُنفذ بعد.
